# IdeaNova デザイン共有版

この配布物の `dist` は、PC内のサーバーに接続せず表示できる共有確認版です。
以前の `IdeaNova_dist_preview_2026-09-12.zip`（ローカルサーバーが必要）とは異なります。

## GitHub Pagesで公開する内容

- リポジトリ直下の `dist/index.html`：企業サイト・農作物ショップ
- `dist/cosmetics/index.html`：化粧品ショップ
- `.github/workflows/pages.yml`：distをPagesへ公開する処理

公開先のリポジトリへ、ZIPを展開した `dist` と `.github` を配置します。ZIPファイル自体を置くだけでは公開されません。
リポジトリの Settings → Pages → Build and deployment → Source を GitHub Actions に設定してください。
既存の公開サイトがある場合は、置き換える前に公開先を確認します。
既定ブランチへ反映すると公開処理が実行されます。Actionsから手動実行もできます。
完了後、PagesのURLを共有してください。URLの末尾に `cosmetics/` を付けると化粧品側に移動します。

`#/company` のようなURLを使用するため、GitHub Pagesのリポジトリ配下でも再読み込みできます。
ドメイン名・リポジトリ名はビルドに固定していません。

## 使えるもの・使えないもの

会社案内、事業紹介、お知らせ・コラム、商品一覧・詳細、カテゴリー検索、問い合わせ等の画面デザインを確認できます。
企業と化粧品は確認用に同じ公開先の別パスへ分けてあります。正式な別ドメイン運用はローカル版・本番接続設計で維持します。
会員登録・ログイン・注文・決済・送信・管理操作はできません。購入ボタン等は確認用の案内を表示します。
フォームの入力内容をサーバーへ送信せず、認証情報・個人情報をブラウザー保存しません。
管理画面・検証シナリオは共有版の対象外です。noindexは検索非掲載の依頼であり、アクセス制限ではありません。

## 確認状況

公開用ファイルだけをGitHub Pagesと同様のサブディレクトリから配信し、画面・ページ移動・再読み込み・同一タブ往復・スマートフォン・送信しない制御を確認済みです。
GitHub上の公開完了は、公開先の指定とPages実行後に確認します。

元のReactプロジェクトでは `npm run build:share` で `dist/share` を生成します。その中身を本配布物の `dist` として配置しています。
元のローカル版（5177/5179）と共通デモサービスは変更していません。

公開処理はGitHub公式の静的サイト用ワークフローを基にしています：
https://github.com/actions/starter-workflows/blob/main/pages/static.yml
