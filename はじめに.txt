IdeaNova 4ページ改修版 / 2026-09-16

トップ・会社案内・お知らせ・コラムを参考画像に合わせて改修したソース一式です。
文字・リンクは操作でき、スマートフォン表示に対応しています。

起動方法
1. Node.js 24（npm同梱）をインストールしてください。
2. 展開したIdeaNovaフォルダーでターミナルを開きます。
3. npm ci
4. npm run dev:all
