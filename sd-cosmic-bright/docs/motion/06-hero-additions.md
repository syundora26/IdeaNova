# 06 追加要望: 惑星の周りの星のきらめきと、輪を周回する光の粒

ユーザー要望「トップの土星みたいなのを回す・周りの星をキラキラさせる」への対応。惑星は1枚の写真風画像（cosmic-hero.webp, 1672×941）に焼き込まれているため自転はできず、推奨案（星のきらめき + 輪の上を周回する光）を実装した。

| ID | 内容 | 実装 |
|---|---|---|
| H6 | **惑星の周りの星のきらめき**: 画像の暗い夜空にあたる 30 か所（画像ピクセル座標で定義）に 4〜5px の星を置き、既存の `twinkle` キーフレーム（3〜7s、不透明度 .15〜.85）で瞬かせる。4 つに 1 つは十字の輝き付き。見出し・リード・CTA（`.hero__inner`）と SCROLL 表示に重なる星は自動的に非表示（フォント読込後・リサイズ時に再計算） | `src/motion/hero.ts`, `motion.css` |
| H7 | **輪を周回する光の粒**: 輪の外縁を画像から最小二乗で楕円フィット（中心 (1435, 366)、長半径 758、短半径 100、傾き −20.35°）し、4 つの光点（7px + ハロー）を 44 秒で 1 周させる。奥側（上側）の半周は不透明度 .5、惑星の円盤（中心 (1232, 432)、半径 345）の裏に入る間は非表示。惑星の前を通る手前側は常に表示 | 同上 |
| 共通 | 画像ピクセル座標 → 表示座標の変換は `object-fit: cover` + `object-position`（computed style から取得）と同じ計算で行うため、PC・タブレット・スマホの切り取り位置が変わっても画像に貼り付いたまま。ヒーローのスクロール視差（H2）は画像と同じ量を 2 層にも適用。ヒーローが画面外のときは周回 tween と瞬きを停止。reduced-motion では両層とも生成しない（静止表示は従来と同一） | `src/motion/parallax.ts` |

## 検証
- `npm run build` 通過。reduced-motion のスクリーンショット 18 枚: 05 と同じ結果（16 枚一致、ヒーロー 2 枚はアンチエイリアス差のみ）。
- motion: 1440 / 1024 / 390 幅で、光点が輪の帯の上に乗り、惑星の裏で消えることを目視確認。表示中の星は 17 / 13 / 14 個（文字と重なる分を除外後）。
- フレーム計測（05 と同じスクリプト）: desktop 平均 23.3〜24.2ms、mobile 17.6〜18.1ms で、追加前（05 の修正後）と差なし。
- console エラー 0、最下部スクロール後の未表示要素 0、CLS 0（scrollHeight 不変）。
