# 07 追加要望: 惑星本体と輪の回転、背景の宇宙のアニメーション

ユーザーの再要望「土星自体と周りの輪っかも回してほしい」「背景の宇宙にもアニメーションを」への対応。

## H8 惑星の自転（WebGL、ライブラリなし）
- 惑星は1枚の絵に焼き込まれているため、`scripts/planet-textures.py` で円盤（中心 (1232, 432)、半径 340 画像px）を **模様（アルベド）** と **陰影（ライティング）** に分離した。
  - `planet-light.webp`（512×512）: 円盤のガウスぼかし（σ26、円盤外を混ぜない正規化畳み込み）。縁の光・明暗はここに残る。
  - `planet-albedo.webp`（1024×768、正距円筒）: 絵 ÷ 陰影。可視半球（経度 ±90°）を球面座標へ逆投影。輪が手前を横切る帯は除外して上下から反射補間、縁（|経度| > 65°）は縁の光の混入と引き伸ばしを避けるため ±65° を軸に反射した模様で置換。裏側はシェーダーで鏡映。
- `src/motion/planet.ts`: 素の WebGL 1、四角形1枚のフラグメントシェーダーで球面をレイキャスト。`albedo(回転後の経緯度) × light(画面位置)` を描くので、開始時は元の絵と一致し、その後は模様だけが流れる。自転軸は輪の楕円から算出（画面内で左へ 20.35°、視線方向へ 7.6°）。周期 110 秒、30fps 上限、DPR は PC 1.5 / スマホ 1.25 まで。
- 手前を横切る輪の帯（フィット楕円の内側 0.90〜1.0）は透明にして元の絵の輪を見せ、円盤の縁は 2px でアンチエイリアス。キャンバスは絵の円盤の位置に重ね、`object-fit: cover` の座標変換で全画面幅に追従。ヒーローの視差（H2）にも同乗。
- 画面外・タブ非表示で停止。WebGL 不可・テクスチャ取得失敗・reduced-motion では生成せず、元の静止画のまま。

## H7' 輪の回転（粒の群れ）
- 既存の 4 つの明るい粒に加え、帯の内側 0.905〜1.0 に 36 個の小さな粒（2〜4px、不透明度 0.45〜0.9）。内側ほど速く（周期 38〜48 秒）、奥側は半減、惑星の裏では非表示。GSAP ticker で 30fps 更新、不透明度は変化時のみ書き換え。

## U2 背景の宇宙のアニメーション
- 星雲の光 2 つ（70vmax / 84vmax の放射グラデーション）が 90 秒 / 120 秒で漂い、明滅（0.7〜1）。
- 背景の色被せ（`.universe:after`）が 18 秒周期で呼吸（不透明度 1 → 0.72）。
- 星空画像と星の層が左右にゆっくり揺れる（各層の幅の ±1.2% / ±1.6%、70 秒 / 55 秒、往復）。層は横にも余白を持たせ（104% / 106%）隙間を出さない。スクロール視差（縦）と合成。
- 流れ星の間隔を 14〜24 秒 → 9〜19 秒に。
- すべて transform / opacity のみ、`html.motion` 配下でのみ生成・適用。

## 検証
- `npm run build` 通過、console エラー 0、最下部スクロール後の未表示要素 0、scrollHeight 不変（CLS 0）。
- reduced-motion のスクリーンショット 18 枚: 従来と同じ（16 枚一致、ヒーロー 2 枚はアンチエイリアス差のみ）。
- 惑星: 開始 2.5 秒時点の円盤は元の絵とほぼ一致、9 秒後に模様が移動し縁の光と輪は静止（verify-hero/planet-sbs.png）。
- フレーム計測（GPU なしのソフトウェア描画環境）: desktop 平均 24 → 31〜34ms、mobile 18 → 24ms。増分の大半は WebGL のソフトウェア描画と大きな星雲層の合成で、実機の GPU では軽い処理。main-thread 側の増分は mobile 4× で Script +0.2s / RecalcStyle +0.4s（12 秒中）。**実機での確認を推奨**。負荷が問題になる場合の切り替え候補: スマホで惑星シェーダーを無効化（`setupPlanet` を `(max-width:767px)` でスキップ）、星雲層を 1 つに。
