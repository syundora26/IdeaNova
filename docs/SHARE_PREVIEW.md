# デザイン共有版とGitHub Pages — 2026-09-12

## 完了したもの

PC内の共通データサービスを使わず、静的ファイルだけで表示する共有確認版を追加しました。企業サイト・農作物ショップを入口に置き、化粧品サイトは同じ公開先の `cosmetics/` に分離しています。元の独立ドメイン用ローカル版とは別のビルドです。

- `npm run build:share` → `dist/share`
- `node scripts/serve-share.cjs` → PC上の確認URL http://127.0.0.1:5183/ （インターネットへの公開URLではありません）
- `deployment/github-pages` → Pagesの公開設定・説明
- 配布ZIP内は `dist/share` の中身をリポジトリ直下の `dist` として配置

`vite.share.config.ts` だけで共有用のルーター・データ取得・フォーム注記へ切り替えます。通常のVite設定、公開APIの型、ローカルの認証・カート・注文・記事保存方式は変更していません。写真・デザインも既存のものを使っています。

## 共有版の動作

- サブディレクトリ対応の相対画像URLと `#/company` 形式のルートを使用。任意のリポジトリ名で動作し、直接アクセス・再読み込み・戻る操作を維持します。
- 商品・記事は既存の確認用データを参照。商品検索・カテゴリー・詳細・会社案内・記事・法務・問い合わせ等の画面を表示します。
- 企業と化粧品は同じタブで往復します。共有版では別パス、元のローカル版・本番設計では従来の別サイトです。
- データ取得は公開表示用の読み取り操作だけを許可。登録・ログイン・カート変更・注文・支払い・送信・管理操作は実行できず、操作時に案内を表示します。
- フォームには確認用の注記を追加。入力は一時的な画面内状態のみで、送信・localStorage・Cookieへの保存を行いません。CSPでも通信とHTMLフォーム送信を禁止します。
- 管理・確認シナリオへのリンクと実装を共有版から除外。直接アクセス時も見つからない画面を表示します。
- 正式情報確認中・写真イメージ・既存の写真出典・法務未確定の表記を維持。noindexはアクセス制限ではありません。
