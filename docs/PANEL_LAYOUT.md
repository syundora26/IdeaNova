# FVの高さ調整・6パネル版

2026-09-11。ユーザー承認済み計画に基づく当時の企業トップです。写真6点、書体、配色、文章、記事データと既存の導線を継続利用しています。

## FV

企業ヘッダーをResizeObserverで測り、企業レイアウト内のCSS変数 `--corporate-header-height` に反映します。FVの最低高さは `100svh − ヘッダー実測値`。ヘッダーの寸法が変化しても再計算し、ショップに移動したときは監視と変数を解除します。

PCでは文字を上下中央寄りに配置。写真はヘッダー背面からFV下端まで広げています。1000px以下は文字と写真の2段にし、写真へ残りの高さを割り当てます。写真の最低高さは260px。高さを固定しないため、長文、横向き、小さい画面では内容に合わせて全体が縦に伸びます。

## パネル

共通部品 `CorporatePanel` で、会社紹介・化粧品・農作物・購入案内・お知らせ・コラムを6面に分けました。各パネルは見出しと関連付けたsectionです。FVと問い合わせフッターは従来の全幅の面として維持しています。

| 仕様 | PC（1000px超） | タブレット（601〜1000px） | スマートフォン（600px以下） |
|---|---|---|---|
| パネルの最大幅 | 1440px | 画面幅内 | 画面幅内 |
| 内側の上下余白 | 80px | 64px | 56px |
| 内側の左右余白 | 40px | 20px | 20px |
| パネル間隔 | 32px | 24px | 24px |
| 角丸 | 12px | 12px | 12px |

境界線は深緑20％の1px。会社紹介・農作物・お知らせは生成り、化粧品・購入案内・コラムは淡い緑を使います。既存セクションの上下余白を共通部品側へ集約し、化粧品・農作物の説明内部の重複余白も除去しました。

各パネルの高さは内容によって変化します。写真の曲線は各写真部品で維持し、文字やフォーカスをパネルの角丸で切り落とす処理は加えていません。文字量の変化を許容するため、農作物と購入案内の見出しは枠内に収まる可変サイズへ調整しています。

## 機能への影響

- 変更範囲は企業トップのパネル、企業ヘッダーの高さ測定、企業限定CSSです。
- 公開API・ShopGateway・会員・カート・注文・記事データ・リンク先は変更していません。
- 化粧品は別サイトへ同一タブ移動。農作物、カテゴリー、会社問い合わせは既存のページへ接続します。
- 写真は独立した素材のままです。参考PNGを画面表示に使用しません。郡山写真の出典と正式情報の確認中表記を保持します。
