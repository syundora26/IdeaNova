# 写真の接続と余白の修正（2026-09-12）

IMG_7664.jpgをデザイン基準として、企業トップの写真の境界と余白を修正しました。参考画像全体をページへ表示する方式は使用していません。女性・商品本体の配置、既存の説明・記事・リンク・確認中表記は維持しています。

## 修正内容

- 石台の下の単色下地と商品下端の透明フェードを撤去。既存の女性・商品写真を基にした自然背景を敷き、商品写真の岩肌を補完した素材の下部を重ねています。商品本体は既存透過素材を使用します。
- 花と収穫は同じ1024×835の座標系で描画。収穫写真を先に、花を後に配置し、曲線の始点を花の背後へ隠しました。中央の尖った谷や、境界線だけが別の写真上へはみ出す状態を解消しています。
- 写真の切り抜きと線は同じパスを使用。各写真の内部で線を描くため、マスクとの座標差は0です。塗り足しは装飾領域内に閉じ、横スクロールを発生させません。
- 街並みを収穫写真の背後から配置。重なりは`sceneGeometry.height - sceneGeometry.cityStart`（835−760）を共通基準幅1024で換算し、画面幅へ追従させました。上端の水平線を曲線へ変更し、下側も緩やかにうねる形にしています。収穫写真の下端がそのまま街並みとの共通境界になります。
- 会社紹介と価値観の幅比例の最低高さを撤去。会社紹介は文章と270〜370pxの写真領域から高さを決め、長文で伸びます。価値観も内容と余白から高さを決めます。本文や操作には負の余白を適用していません。

1887px幅では、会社紹介が約525pxから394px、価値観が約310pxから193pxへ変わりました。本文の省略や切り捨ては行っていません。

- 1024×900、1440×900、1920×1080、1887×1080、1440×1080、768×1024、390×844、320×740、844×390の9条件で横はみ出しなし。主要操作52px以上。

- メニューのEnter・Tab・Escape、フォーカス復帰、現在地を確認。「本文へ移動」はキーボード時のみ表示し、本文へフォーカスが移動します。
- 記事の読込・空・通信失敗・再試行、問い合わせの入力不備・確認・編集・送信失敗後の入力保持・再試行を応答fixtureで検証。実メール送信なし。
