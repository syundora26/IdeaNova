# 高さ・余白の修正 — 検証結果

実施日：2026-09-12。Windows / Microsoft Edge（Playwrightのヘッドレス表示）。現在稼働中のローカルプレビューと、両サイトの生成済みビルドで確認しました。

## 判定

現行の合否基準は、読みやすさ・自然なスクロール・内容に応じた高さです。旧仕様の「参考画像と±10px」や「全幅で同じ縦横比」は撤回済み。写真の細部の一致、本番認証・実決済・実メール送信は検証対象ではありません。

- 1440×900：ヘッダー72px＋FV558px＝630px。両事業の見出しの下端849pxで、初期画面内に表示。
- 1920×1080：ヘッダー72px＋FV648px＝720px。両事業の見出しの下端939pxで、初期画面内に表示。
- 1440×900と1920×900で、事業・会社紹介・価値観・お知らせの高さが同じ。本文も18pxのまま維持。
- 事業見出しとボタンの上下位置を左右で整列。主要操作52px以上、記事行64px以上。
- 全9表示サイズで横スクロールなし。長文・写真差し替え・横向き・2倍の文字サイズを追加確認。
- 画像JPGへの通信を遮断した状態でも全要素表示。見出しの文字選択、独立部品の差し替え、曲線と輪郭の同一定義を確認。

## 維持事項・制限

現在の会社説明・記事・ショップ導線・街並みのイメージ表記・確認中表記を維持。外部API、本番公開、ドメイン変更、購入機能の追加はありません。実端末とSafari／Firefoxでの追加検証は未実施です。自動アクセシビリティ検証は画面全体の使いやすさを保証するものではなく、キーボードと主要画面の目視確認を併用しています。
