### 記録した差・限界

- 写真は添付画像を参照して補完した別素材です。顔・髪・花・手・商品と岩の細部や形には差があります。完全な画像抽出・画素一致としては納品していません。
- 参考に細い手書き文字がありますが、実装は同梱の筆記体による近似です。ロゴの葉と価値観アイコンも独立したSVGです。
- 参考内の小さい英字・ナビ・ニュース・ラベルを14px以上にしたため、一部の文字幅と行間が広がっています。PCの一般本文は1024pxで14px、1440pxで約20px。1000px以下では17px以上です。
- ボタンは参考に近い細いピル枠を描き、操作領域を52px以上にしています。スマートフォンでは枠そのものも52px以上になります。
- 街並みの注記は写真の下に21px分確保します。その分、価値観セクションの前余白を減らし、アイコン位置とお知らせ開始位置を揃えています。
- 実際の掲載記事・法務リンク・確認中表記を維持したため、参考の架空記事やSNSの配置とは異なります。フッターには約65pxの制作プレビュー案内が加わり、全体は約1607pxです（参考1536px）。
- 1000px以下は参考の縮小画像にせず、縦配置で再構成しています。植物の場所・大きさも読みやすさを優先しています。
