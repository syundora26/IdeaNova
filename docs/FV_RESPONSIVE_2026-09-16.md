# FVレスポンシブ修正 — 2026-09-16

## 変更
- 幅比例のFV高さを撤去。PCは最低640px・通常100svh、最大1440pxの独立した文字／商品グリッド。
- 商品の切り抜き・絶対配置と事業写真による覆いを撤去。写真はcontainで全体表示。
- FV背景・商品・事業背景を分離。曲線と境界は背景層で描画。
- 1000px以下は文字→商品→スクロール案内。商品領域280〜420px。
- 人物のいない既存素材、コピー、ショップ導線を維持。公開API／会員／カート／注文の変更なし。
- GitHubへの公開更新は未実施。

## 検証
- 1920×1080、1440×900、1366×768、1024×768: FVは各画面高と一致。見出し／説明／商品全体が画面内、次の事業紹介と分離。
- 768×1024、390×844、320×740、844×390: 横はみ出し0。全画像のデコード成功。
- 4幅で文字サイズ2倍＋説明8回分: 領域が伸び、文章と商品がFV内に収まる。
- 200%ズーム相当のCSS表示領域960×540でリフロー確認。実ブラウザのズーム操作そのものではなく、縮小したCSSビューポートによる検証。
- 化粧品への同一タブ移動、戻る、農作物、記事詳細、問い合わせ: 成功。
- モバイルメニュー・Escape、スキップリンクのTab往復とEnterによる本文フォーカス: 成功。
- axe自動検査: 1440pxと390pxでWCAG2A/AA違反0。JSエラー0。
- TypeScript、企業／化粧品のローカル用ビルド成功。既存ユニットテスト53件成功。
- 低い画面・拡大表示では1画面への圧縮より内容の表示を優先する。
