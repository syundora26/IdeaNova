## 追加承認事項

| 今回の要求 | 実装 |
|---|---|
| `/shop`入口、企業向け事業詳細 | 農作物中心のShopHome、企業の化粧品紹介から専用サイトへ同一タブ移動 |
| 企業・ショップ・管理の枠組み分離 | App、独立したProvider、企業側だけに共通管理 |
| 別ドメイン・個別ビルド | site.ts、Vite modes、5177/5179、公開設定未入力の停止 |
| 共通会員とサイト別Cookie | httpGateway.ts、server/demo.mjs。相互ログインと片側ログアウトを検証 |
| 期限付きカート移行 | MigrationPages、10分のID、価格/在庫/販売停止再検査、再確認、再適用による重複なし、元データ保持 |
| 共通管理 | 2事業注文と3窓口問い合わせ。化粧品側の管理RPC拒否 |
| 既存パスの置換と復帰先保持 | routerのcanonicalPath / safeNext |
| デモシナリオの専用画面 | `/preview`。通常画面にはスイッチを並べない |
| 日本企業・郡山感 | 実写市街地、日本語の見出し、白・紺・淡いグレー、角形の操作部品 |
| 在庫・価格・販売停止の直前変更 | 注文確定を停止、入力保持、再見積／カート修正 |
| 本番接続設計 | CONNECTION_SPEC.md、DOMAIN_SEPARATION.md、domain.ts、HTTPアダプターと共通サービス |
