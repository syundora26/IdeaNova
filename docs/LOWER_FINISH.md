# 下部の装飾と輪郭の仕上げ — 2026-09-12

参考：ユーザー提供の IMG_7664.jpg。企業トップの価値観・お知らせと、企業共通フッターを修正しました。FV・事業紹介・街並みの配置は維持しています。

## 変更した見た目と部品

- 価値観右下に、薄い布・ガラス容器・葉の独立した写真装飾を追加。元画像のように右下から斜めに入る構図にしました。背景へなじむ合成と端のマスクを施しています。
- 値とお知らせに繰り返していた縦長の葉を撤去。お知らせには別の透過した枝を配置し、文字を避けながら背景の波形をまたいで問い合わせの背後へつなげました。
- お知らせとフッターの水平な境界を、独立したSVGの浅い波形へ変更。文字・記事・操作は切り抜いていません。
- 問い合わせの角丸指定を撤去。左がふくらみ、上辺が右へ下がるSVG輪郭へ変更しました。上部と左側の接線を合わせ、角が出ない形にしています。
- PCの問い合わせはフッター内幅の25％、基本の幅／高さを1.6に設定。1024pxでは文字とフッターの最低高さを優先するため約1.43になります。スマートフォンは全幅で、長文に応じて伸びます。

配置は `ReferenceHome.tsx`、独立装飾・波形・朱色の輪郭は `CorporateMedia.tsx`、表示幅・重なり・素材のなじませ方は `reference.css` に整理しました。

追加部品は `LowerDecoration`（values / news）、`ContactContour`。背景波形は `FooterCurve` を実際のフッターに接続しています。ロゴ・問い合わせ文言・メールアイコン・矢印・記事はそれぞれ編集可能なHTML／React UIです。装飾には読み上げ・フォーカス・ポインター操作を持たせていません。
