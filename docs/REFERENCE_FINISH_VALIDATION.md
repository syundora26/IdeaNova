# 参考構図の仕上げ — 検証結果

## 視覚確認

1024px幅で参考と実装を同じ幅に表示し、FV・2事業・会社紹介・価値観・お知らせ・フッターを個別に確認しました。全体比較と修正前後も記録しています。

- 女性、見出し、商品を上部に配置。ボトルの金色の上端は約302pxで、参考の約315pxに対し約13px上。商品は独立した既存透過素材です。
- 花と収穫の境界が共有区間でつながります。切り抜きと線は同じパス定義。中央で独立した線が交差する状態を撤去。
- 商品下端は既存の石台をフェードし、別の石台画像を継ぎ足す方式を撤去。写真の元の質感は参考と完全には一致しません。
- 花びらと画面端の植物は参考を入力に補修。細い輪郭のボタン、明朝体、深緑・生成り・朱色、非対称フッターを維持。
- 1024pxでの会社紹介前の大きな空白を撤去。街並み写真の上端は約809px、右端は画面端まで表示。
- 1920pxではスクロール案内が明るい面に重ならないことを確認。320pxの会社見出しは2行、価値観の各名称は1行。
