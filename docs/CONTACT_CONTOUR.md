# 問い合わせの輪郭修正 — 2026-09-12

元画像 IMG_7664.jpg の朱色の輪郭を基準に、問い合わせ部分を修正しました。

## 変更

- 上辺の曲線をSVGの表示範囲内へ収め、上端で切れていた平らな部分を解消。
- 左上・左側・左下を接線方向がつながる曲線へ変更。左下は水平な下辺へ滑らかに接続。
- SVG上端に4座標単位の余裕を確保。右端はページ端まで朱色を表示。
- 文字2倍で発見した既存のはみ出しを修正。比率で高さを制約する代わりに、従来のPC幅（フッター内幅95％×25％）と1.6の比率から最低高さを求め、文章が増える場合は伸びるようにしました。1000px以下は既存の最低高さを維持します。

変更した実装は `src/CorporateMedia.tsx` の輪郭と `src/reference.css` の問い合わせ高さ指定のみです。文字・アイコン・矢印・植物・背景の波形・リンク・記事・会員・カート・注文は変更していません。新規画像素材はありません。

## 検証結果

- 1024・1440・1887・1920・768・390・320pxで、上辺と左下を画面記録して確認。
- 通常の問い合わせ・SVG・文字・アイコン・矢印の座標と寸法は、修正前との差0.1px未満。
- 横はみ出し、葉と「お知らせ一覧」の文字の重なりなし。長文は内容に応じて伸長。
- 1024・390・320pxで文字を2倍にして、文字・矢印のはみ出しがないことを確認。OS倍率ではなくブラウザー上の文字サイズで検証。
- 会社案内・会社問い合わせ・プライバシーポリシーで共通フッターを確認。
- キーボードのフォーカスとEnterによる問い合わせへの移動を確認。
- 両ショップ・管理画面に企業用の輪郭が配置されないことを確認。
- TypeScriptと企業・化粧品の両プレビュービルドを確認。ビルド画面の操作7項目も確認。

検証環境はWindowsのMicrosoft Edge（Playwright）。実端末、Safari、Firefoxは今回未確認です。本番公開は行っていません。
