# 提供画像に基づくIdeaNova企業HP

2026-09-11。今回のデザイン基準はユーザー提供の `9e0295eb-0349-4abb-894c-0d1e4ff70d8f.png` です。以前の公開HPの会社情報は利用していません。

## 実装

- トップ：明朝体の「暮らしに、いい芽を。」、街並み・トマト・化粧品の曲線写真、会社紹介、化粧品事業、農作物事業、購入案内、お知らせ、コラムの順。
- 企業共通：IdeaNovaと朱色の丸のロゴ、購入ボタン付きヘッダー、曲線と植物のある深緑の問い合わせ・フッター。
- 色：深緑 `#093E32`、生成り `#F7F4EC`、朱色 `#AE3924`。ショップ案内背景は生成りの派生色。
- 書体：Noto Serif JP 400 / 500 / 600。企業内に限定し、フォーム等は既存のNoto Sans JPも継続。フォントは配信ファイルに同梱。
- PCでは画像の793pxを基準に比率を指定し、最大1600pxまで拡大。1000px以下は縦方向の構成に切り替え、本文17px以上、補足14px以上を確保。
- 見出し・説明・リンク・記事はHTML。写真は提供PNGを変更せず、SVGの表示領域と曲線マスクで使用。Webページ全体を画像で表示する方式ではありません。
- トップの写真のみ短いフェード。動きを減らす設定では停止。
- 写真の装飾中の「01/03」は静止画像の一部で、スライダー操作ではありません。

## 既存機能との接続

- 化粧品の専用サイトボタンは既存の設定済み別サイトへ同一タブで移動。
- 農作物の購入ボタンは `/shop/agriculture`。野菜・果物はカテゴリー指定付きURLへ移動し、商品一覧がその条件で表示される。
- 記事のタイトル・公開状態・本文は既存のShopGatewayの情報を使用。提供画像中の仮記事タイトルに上書きしていないため、文言とカードの順番は参考画像と異なる。
- 企業・農作物・化粧品の会員、カート、注文の保存方式やAPIは変更しない。
- 下部に制作プレビューの注記と既存の法務・管理入口を残す。

## 一致の範囲と素材

構成、曲線、写真、色、タイポグラフィを提供画像に合わせた再現です。完全な画素一致ではありません。ブラウザの文字描画、Webフォント、実記事、画面幅への対応により差があります。写真の元画像は793×1983pxなので、拡大時の鮮明さには限界があります。

提供画像の街並みの撮影場所は確認できないため、郡山市の実写とは断定していません。会社案内ページで継続使用する既存の郡山写真には、従来の出典表記を維持しています。正式商品・会社情報の確認中表記も維持しています。
