# IdeaNova企業HP — 深緑・生成り・朱色のリデザイン

2026-09-11。50〜70代にも読みやすい、郡山の地域企業のHPを想定。React / TypeScript / Vite / CSS / GSAPを継続使用。

## 適用範囲
トップ、会社案内、事業紹介（一覧・化粧品・農作物）、お知らせとコラムの一覧・詳細、会社問い合わせ、企業側の法務ページ。
企業ヘッダー・本文・フッターを包含する `.corporate-layout` にのみ新しいテーマを適用する。
農作物ショップ、独立化粧品ショップ、管理画面は従来のテーマを維持する。共通の会員・カート・注文・ShopGateway・API契約は変更していない。

## 配色と可読性
| 色 | 値 | 用途 |
|---|---|---|
| 深緑 | #214C40 | 見出し・本文・標準ボタン |
| 生成り | #F7F3E8 | 背景、塗りボタン内の文字 |
| 朱色 | #A13E2B | 重要な問い合わせ操作、現在地、区切り・入力エラー |

派生色は淡緑 #E9EDE2、淡い朱色 #F0E5D8。写真の色は制限しない。
深緑/生成り8.72:1、朱色/生成り5.85:1、深緑/淡緑8.14:1、朱色/淡い朱色5.22:1。いずれも通常文字4.5:1以上。

書体はNoto Sans JP、本文PC18px/スマートフォン17px、行間1.8。主要操作は17px/16px、補足文字は14px以上。見出し700、操作500、本文400。
FV見出しはPC56px、コンパクトPC・タブレット48px、スマートフォン32pxで2行。長い記事タイトルは自然改行を許容する。

## FVとセクション
参考：https://www.jyuutaku-family.co.jp/
大きな見出しと曲線的な写真帯という構成を参考とし、コード・ロゴ・写真・コピーは流用しない。

FVは「郡山から、暮らしのそばへ。」と「福島県郡山市を拠点に、化粧品と農作物をお届けするIdeaNovaです。」を日本語で表示。「事業紹介」ボタンを初期表示内に配置。
PCは右下へ広がる曲線の写真帯、1000px以下は本文の下へ帯を移動し、767px以下は街並みと上下の事業写真を組み合わせる。
郡山の写真を主役に、化粧品と農作物の既存イメージを補助として配置。帯のみ初回表示0.55秒フェード。自動スライド、スクロール固定、操作を妨げる演出は設けない。prefers-reduced-motionでは静止する。

順序：FV → 最新のお知らせ → 会社紹介 → 二つの事業 → コラム → お買い物の案内 → 会社問い合わせ。
見出しの下に短い説明、内容、案内を配置。事業は同寸法の画像を2列に配置し、スマートフォンは1列。
会社紹介は文章中心、お知らせは行形式、事業とコラムは画像付き、お買い物は目的別の案内とし、統一した部品の中で内容に適した形式を使い分ける。
記事の読込・空・通信失敗・再試行を明示する。

## 共通部品とレイアウト
- `CorporateUI.tsx`：CorporateHeading、CorporateButton、CorporateArticleList、ArticleState。
- `Corporate.tsx`：企業ページ、写真帯、会社・事業・記事・ショップ案内。
- `corporate.css`：企業専用テーマとレスポンシブ指定。既存の共有CSSはショップ・管理のため維持。
- 共通Headingを使う会社問い合わせと法務ページにも、企業レイアウトの範囲で同じタイトル・文字ルールを適用。
- 企業ヘッダーは高さ72px。1250px以下は「メニュー」とアイコンの開閉式。Escapeで閉じ、メニュー内からならボタンへフォーカスを戻す。ページ移動後は本文へフォーカス。
- 本文最大1200px、左右PC40px/スマートフォン20px。セクション余白96px/56px。
- ボタン高さ56px、角丸8px。矢印は装飾として読み上げから除外し、日本語で目的を示す。
- 会社問い合わせは朱色の操作を使用。ラベル・必須表示・入力欄・直下の不備説明を配置。native constraint validationを利用して日本語のエラーを出し、aria-invalid / aria-describedbyと最初の不備へのフォーカスに対応。ショップ側は従来の挙動を維持。
- 正式な問い合わせ送信・認証・決済の追加接続は行わない。

## サイト間の移動
企業内の農作物ショップと独立化粧品ショップを目的別に案内。「化粧品専用の別サイトへ移動します」と明示。既存router/site設定経由の同一タブ移動を継続。
GatewayProviderはレイアウト外側のまま。サイト別Cookie、商品ID・数量の保存、旧URL、旧カート移行、注文スコープを変更しない。
