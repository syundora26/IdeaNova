- 福島県郡山市を拠点に、化粧品・農作物の2事業を紹介する企業サイト。
- トップ：FV → 2事業 → 会社紹介 → 4つの価値観 → お知らせ → フッター。
- メインコピー：美しさが、未来をつくる。
- 葉のSVGロゴ、明朝体、深緑・生成り・朱色。写真・文字・曲線・操作は独立したUI。
- 農作物は企業側のショップ、化粧品は独立サイトへ同じタブで移動。
- コラムとカテゴリー検索は既存のメニュー・ショップから利用可能。
- お知らせとコラムを合わせた最新3件を、元の詳細URLへ接続。
- 写真素材は提供画像から再構成したイメージ。花びらと画面端の植物を補修。トップの風景には「街並みはイメージです」と明記。
- 正式な会社情報・連絡先・商品・運用条件は確認中。旧HPの会社情報は使用しない。

## 2026-09-19 改修（デザイン修正・高さ・アニメーション・モバイル構図）

- 高さ・余白はトークン化（`src/reference.css` の `.corporate-layout`）。FVは `--fv-h = clamp(600px, 100svh − peek, 880px)`、余白は `--sp-s / --sp-m / --sp-l`。PC用の上書き（旧 editorial.css 90–97行）は reference.css に統合。
- スマホ（≤1000px）もPCと同じ構図：生成りの曲線＋深緑の帯（`HeroPhotographs` の mobile パス）、事業ブロック間は曲線マスクでつなぐ。
- アニメーションは `src/motion.ts`（GSAP + ScrollTrigger、`gsap.matchMedia` で reduced-motion とブレークポイントを分岐）。`navigator.webdriver` または `?nomotion` で停止。写真は transform のみで動かし、LCPを遅らせない。
- 画像は `scripts/optimize-images.mjs` で WebP（800w / 1600w）を生成し、`responsiveSet()` で srcset を付与。元PNGは既存テストが参照するため残置。
- フッターの「制作プレビュー／確認シナリオ／管理画面」は `demoEnabled` のときだけ表示。
