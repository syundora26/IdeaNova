# IdeaNova 独立素材・React UI版

2026-09-11。ユーザー承認済みの「提供デザインを、独立した素材とReactのUIで実装し直す」計画に基づく素材制作記録です。

## UIの構成

企業トップと共通ヘッダー・フッターを対象に、提供されたデザインPNGから写真部分を切り抜く方式を撤去しました。写真は独立ファイル、文字は選択可能なHTML、曲線・写真間の境界・葉はSVG/CSSです。Webサイトの画像をページとして表示する構造ではありません。

- FVは郡山・トマト・化粧品の3枚の独立画像。文字、丸い句点、スクロール案内はHTMLです。静止表示と初回の0.6秒フェードを採用し、動きを減らす設定では停止します。旧画像中の `01/03` は表示しません。
- 会社紹介、化粧品、農作物、お買い物、お知らせ、コラムの順。会社紹介には郡山写真の出典を表示します。
- 深緑 `#093E32`、生成り `#F7F4EC`、朱色 `#AE3924`、Noto Serif JPを維持。フォームは既存の読みやすい日本語UIを継続します。
- Grid/Flexと内容に応じた高さを使用。デザイン画像の幅793pxに依存した一律拡大単位は廃止しました。写真と装飾の重なりだけを独立した領域で制御します。
- 1000px以下では主要セクションを縦に配置。本文17px以上、補足14px以上、主要ボタン52px以上。コラムカードは600px以下で1列です。
- 写真の上の「旬がつなぐ、やさしい食卓。」もHTML。背景との読みやすさのため深緑の面を添えています。

## 編集箇所と入出力

`src/CorporateMedia.tsx` が素材と写真表示を管理します。`CorporatePhoto` は `src`、`alt`、`position`、`shape` を受け取り、必要に応じて `srcSet`、`sizes`、`eager` を指定します。曲線は表示枠の0〜1の範囲を使い、元画像のピクセル座標から独立しています。葉は `LeafDecoration` のベクター図形です。

`src/ReferenceHome.tsx` に見出し・説明・導線を、`src/reference.css` に企業限定のレイアウトを配置しています。記事タイトル・順番・公開状態は従来のShopGatewayの値をそのまま使います。

公開API、ShopGateway、認証、カート、注文の型と保存方法は変更していません。化粧品は設定済み別サイトへ同一タブで移動。農作物とカテゴリー絞り込みは従来どおり企業側のショップへ接続しています。ショップ・管理用のスタイルには適用しません。
