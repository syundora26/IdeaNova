# 添付画像に基づく企業トップ（現行版）

2026-09-12。唯一のデザイン基準は IMG_7664.jpg。画像の雰囲気のみを使った前版から、写真・文字・曲線の位置関係を再現する構成へ変更しました。「FV70svh」「初期画面に両事業を見せる」「一律64/80/48pxの余白」の条件はユーザーの選択により撤回済みです。

## 構図と独立UI

- PCのヘッダーは写真に重ねます。トップ以外のヘッダーは通常の文書順を維持。
- FVと2事業の写真を一つの装飾領域で配置。文章は通常のGrid/Flexの文書順に置き、内容が増えた場合は伸びます。
- 通常の1024px幅では写真領域が835px。会社紹介、価値観、お知らせ、フッターを続けます。
- 両事業の曲線は同じ交点と共有区間を持ちます。切り抜きと境界線は同じパス文字列を使用し、左右別々の切り抜きで発生していた線の交差を撤去。
- 商品は既存の本物のアルファ付き素材。別の石台を継ぎ足す部品を撤去し、位置・サイズ・石台下端のマスクを調整。
- スクロール案内は本文とは別のGrid行に置き、幅が変わっても深緑の帯上に表示。
- 明朝体、葉のSVGロゴ、細いボタン枠、朱色の非対称フッターを使用。
- 1000px以下は文章→女性・商品→化粧品→農作物の縦配置。写真は280〜420px。
- 本文18px／小画面17px、補足14px以上、主要操作52px以上。ボタンの細い輪郭は操作領域の内側に描画。

参考はスマートフォン仕様を含まないため、小画面は読みやすい縦配置を採用。参考にはない実際の記事、法務リンク、イメージ表記、制作確認中表記も維持しています。これらの高さを画像に合わせて削除・縮小していません。

## 機能の維持

公開API・ShopGateway・会員・カート・注文・記事データ・保存方式の変更なし。企業トップ、化粧品別サイト、農作物ショップの同一タブ移動、共通管理を維持。実認証・実決済・実メール・本番公開は対象外です。旧HPの会社情報は追加していません。
